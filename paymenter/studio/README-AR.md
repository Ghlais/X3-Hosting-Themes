# X3 Rackline Studio 3D — 1.4.0

تحديث للثيم الحالي **x3-hosting** على **Paymenter 1.5.9 وPHP 8.3+**. يتطلب ثيم X3 Rackline 1.1.0 الأساسي، ويضم ملفات تحديث الشراء والعمق السابقة. لا تحتاج تعيد تركيب 1.2 أو 1.3 بشكل منفصل.

## التصميم

- مشهد ثلاثي الأبعاد مبني بـ CSS للراك، بإضاءة أرضية وواجهات مجسّمة. الحركة تتبع مؤشر الماوس وتقدر توقفها من الزر أسفل المشهد، أو من إعداد الحركة الحالي. التصميم يحترم تقليل الحركة في الجهاز.
- نفس الأسطح والإضاءة والبطاقات تمتد إلى المتجر والمنتج والشراء والسلة، ومنطقة العميل والخدمات والفواتير والتذاكر والحساب وتسجيل الدخول والتسجيل.
- العربية من اليمين والإنجليزية من اليسار، مع دعم الهاتف والمظهر الفاتح والداكن. المجسّم توضيحي؛ مصابيحه لا تعرض حالة السيرفر الفعلية.
- معلومات الحساب والحالات والأسعار تأتي من Paymenter. الشراء والفواتير وطرق الدفع وتقديم التذاكر تبقى بالمسارات الأصلية. لا توجد إضافة دفع جديدة ضمن هذا التحديث.

## التركيب

**ارفع ZIP إلى `/tmp` أو مجلد خارج الموقع. اسم المجلد `X3-Studio-3D-v1.4.0` هو اسم الحزمة، والثيم المفعّل يبقى `x3-hosting`.**

```bash
cd /tmp
unzip X3-Studio-3D-v1.4.0.zip
cd X3-Studio-3D-v1.4.0
php install.php --root=/var/www/paymenter
php install.php --root=/var/www/paymenter --apply
php check.php --root=/var/www/paymenter
```

السطر الأول الذي يشغّل المثبّت للفحص فقط. انتظر `Preflight OK` ثم نفّذ أمر التركيب. بعد التركيب يجب أن تظهر `active_theme: x3-hosting` و`errors: []` و`warnings: []`. افحص الرئيسية والمتجر والشراء وحساباً تجريبياً قبل استقبال الطلبات، وحدّث المتصفح تحديثاً كاملاً.

المثبّت يحفظ الملفات القديمة قبل استبدالها. يبقي التذييل وروابطه والشعار والصور وإعدادات الثيم وملفات Vite الأساسية. يضيف سطر تحميل الملفات إلى رأس التخطيط إذا لم يكن موجوداً، ويحفظ بقية تخطيطك. التغييرات اليدوية في القوالب المستبدلة موجودة في النسخة الاحتياطية. لا يكتب قاعدة البيانات أو Paymenter core، ولا يحتاج npm. أصول العمق 1.3.0 تبقى جزءاً من الحزمة، ورقم تصميم Studio هو 1.4.0؛ رقم ثيم Rackline الأساسي في `theme.php` يبقى كما كان.

إذا ظهر أن الثيم المفعّل هو **اسم الحزمة** وواجهة الإدارة لا تفتح، صحح الاختيار من داخل مجلد Paymenter:

```bash
cd /var/www/paymenter
php artisan tinker --execute='\App\Models\Setting::updateOrCreate(["key"=>"theme","settingable_type"=>null],["value"=>"x3-hosting","type"=>"string"]); \App\Providers\SettingsProvider::flushCache(); dump(config("settings.theme"));'
php artisan view:clear
```

## التراجع

المثبّت يطبع أمر التراجع مع المسار الصحيح تحت `storage/app/x3-studio-backups/`. احتفظ بالأمر ومجلد الحزمة. مثال، استبدل `BACKUP_NAME` بالاسم المطبوع:

```bash
php install.php --root=/var/www/paymenter --rollback=/var/www/paymenter/storage/app/x3-studio-backups/BACKUP_NAME
php install.php --root=/var/www/paymenter --rollback=/var/www/paymenter/storage/app/x3-studio-backups/BACKUP_NAME --apply
```

الأمر الأول يفحص النسخة فقط. الثاني يعيد الملفات السابقة، ويحفظ الملفات المستبدلة أثناء التراجع. لا يلزم تراجع قاعدة البيانات لهذا التحديث.

نتائج الفحص المحلي وحدوده في `VALIDATION.json`. صور المعاينة تستخدم بيانات اصطناعية محلية. اختبر بوابات الدفع الفعلية والتخصيصات على موقعك؛ لا تحتوي الحزمة حسابات تجريبية أو مفاتيح أو قاعدة بيانات.
