# Rackline Studio design reference

The shared surface, rim, highlight and depth tokens live in public/x3-hosting/studio-v1.4.0.css. The cabinet and stacked tokens are separate CSS planes, with no 3D downloads. Use metallic navy/graphite surfaces, cold silver highlights, beveled edges and consistent spacing. Page headings and catalog motion stay restrained. Geometry remains visible when motion is off.

Keep Arabic direction in the document; only decorative machine geometry is LTR. Portal panels use the same visual language as the storefront. The cabinet LEDs are illustrations. No live status or operational metrics are implied by them.
