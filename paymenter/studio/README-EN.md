# X3 Rackline Studio 3D 1.4.0

Cumulative theme update for existing X3 Rackline 1.1.0 on Paymenter 1.5.9, PHP 8.3+. Extract outside the application themes and public directories. Keep active theme x3-hosting. The package name is not a theme slug.

Run php install.php --root=/var/www/paymenter for preflight, then add --apply to install. Run php check.php --root=/var/www/paymenter. Preserve the printed rollback command. See README-AR.md for copyable commands and recovery details.

Includes CSS 3D Rackline geometry, storefront and checkout, customer portal, billing, services, tickets, account and authentication screens. Uses native pricing, payments, validation and authorization. No additional dependencies or Vite build. Preserves existing footer, assets, theme configuration and core. Preview data is synthetic and is not shipped.
