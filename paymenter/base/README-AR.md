# X3 Hosting — Rackline 1.1.0

مخصص لـ **Paymenter 1.5.9 وPHP 8.3+**. نسخة مطوّرة من ثيمك الحالي بنفس الاسم `x3-hosting`، مع ملفات CSS وJavaScript والخط العربي مبنية وجاهزة. لا تحتاج Node أو Composer للتثبيت كما هي.

## ما أُضيف

- إعدادات رابط ونص زر التذييل باللغتين، Discord والدعم وروابط إضافية.
- مواصفات عامة مرتبطة برقم المنتج: المعالج والرام والتخزين والشبكة والموقع، ودعم نصوص عربية وإنجليزية. تظهر فقط المواصفات التي تُدخلها، والأسعار من Paymenter.
- اختيار المنتجات الموصى بها ومنتجات الرئيسية؛ مقارنة باقتين أو ثلاث مع بيان دورة الفوترة ورسوم الإعداد.
- خمسة أسئلة شائعة قابلة للتعديل باللغتين؛ رسومات Rackline أصلية مختلفة لأقسام compute وgame وapps.
- مراحل إعداد الطلب → السلة → الدفع، وبيان المبلغ الدوري ورسوم الإعداد. تبقى إجراءات الشراء والبوابات والضرائب والمخزون بيد Paymenter.
- أعلى لوحة العميل: أقرب الفواتير بانتظار الدفع بالمبلغ المتبقي، والخدمات الدورية الفعالة المستحقة خلال 30 يوماً، واختصارات الإدارة والتذاكر.
- خط Noto Sans Arabic محلي مع ترخيصه، ودورات فوترة عربية مصقولة، وعزل اتجاه الأرقام والمبالغ، وتحسين الهاتف والتذييل وجداول المقارنة.

## التركيب أو تحديث نسختك الحالية

ارفع **ملف ZIP إلى `/tmp/`**. لا تفكّه داخل `themes/x3-hosting` أو `public/x3-hosting`؛ فهذا هو سبب تداخل المجلدات السابق.

نفّذ الأوامر التالية بعد الرفع:

```bash
mkdir -p /tmp/x3-release-1.1.0
unzip /tmp/X3-Hosting-Paymenter-Rackline-v1.1.0.zip -d /tmp/x3-release-1.1.0
cd /tmp/x3-release-1.1.0/X3-Hosting-Paymenter-Rackline-v1.1.0
php install.php --root=/var/www/paymenter
php install.php --root=/var/www/paymenter --apply
php tools/check.php --root=/var/www/paymenter
```

الفحص الأول لا يبدّل الثيم. أمر `--apply` يتحقق من البصمات والإصدار، يجهز الملفات، ينقل الثيم والأصول القديمة إلى نسخة احتياطية خاصة، يركب النسخة الجديدة ثم ينفّذ `view:clear`. عند فشل هذه الخطوة يعيد المجلدين السابقين تلقائياً. لا يمس `.env` أو قاعدة البيانات أو `app` أو `routes` أو `config` أو `vendor` أو الثيم الافتراضي.

إذا كان `x3-hosting` مفعلاً عندك، يبقى مفعلاً وتبقى إعداداتك المحفوظة. تعديلات القوالب اليدوية تبقى في النسخة الاحتياطية ولا تُدمج تلقائياً؛ انقل رابط التذييل المعدّل إلى إعداد الرابط الجديد. في التركيب الأول اختره من إعدادات المظهر في إدارة Paymenter واحفظ. ثم راجع صفحة إعدادات الثيم لإضافة مواصفاتك وروابطك.

الشكل الصحيح بعد التركيب:

```text
/var/www/paymenter/themes/x3-hosting/theme.php
/var/www/paymenter/themes/x3-hosting/views/home.blade.php
/var/www/paymenter/themes/x3-hosting/lib/Theme.php
/var/www/paymenter/public/x3-hosting/manifest.json
```

## الإعدادات الجديدة

إدارة Paymenter → إعدادات الثيم. أسماء الحقول باللغتين. راجع `docs/SETTINGS.md` للأمثلة.

- **Footer button URL**: ضع رابطك هنا لتغيير وجهة زر Powered by. عدّل نص الزر الإنجليزي والعربي في الحقلين بعده. الروابط المقبولة `https://…` و`http://…` أو مسار داخلي يبدأ بشرطة واحدة `/`.
- **Discord URL**: فارغ = الرابط مخفي. **Support URL**: فارغ = صفحة التذاكر الأصلية عندما تكون مفعلة.
- **Homepage product IDs**: أرقام المنتجات، تفصلها فاصلة إنجليزية؛ بحد أقصى ستة. فارغ = أول ثلاثة منتجات ظاهرة حسب ترتيب Paymenter. المنتجات المخفية لا تظهر.
- **Recommended product IDs**: علامة «موصى بها» للمنتجات التي تختارها؛ لا تعني أنها الأكثر مبيعاً.
- **Public product specifications**: خريطة JSON بمواصفاتك الفعلية. لا تضع كلمات مرور أو بيانات Pterodactyl فيها. هذه مواصفات عرض عامة؛ لا تغير موارد السيرفر أو السعر.
- **Category hardware art**: رقم القسم مقابل `compute` أو `game` أو `apps`. الفارغ يستخدم compute.
- **FAQ**: لكل سؤال وجواب حقل عربي وإنجليزي. اترك السؤال أو الجواب فارغاً لإخفاء ذلك السؤال، أو عطّل القسم كاملاً.

## التحقق بعد التحديث

أداة الفحص يجب أن ترجع `errors: []`، ويكون `active_theme` هو `x3-hosting` ومسار `home` داخل الثيم نفسه. عند تعديل المصدر بنفسك يصبح اختلاف البصمة متوقعاً؛ استخدم الحزمة الأصلية للفحص قبل التخصيص.

افتح الرئيسية والقسم والمنتج والسلة بالعربي والإنجليزي وعلى الهاتف. اختَر باقتين وافتح المقارنة وأغلقها. راجع السعر ودورة الفوترة والإعداد قبل تأكيد الطلب. من حساب تجريبي افحص لوحة العميل والفاتورة والتذاكر. اختبر بوابة الدفع الفعلية في وضع الاختبار الخاص بها قبل الاعتماد التجاري؛ الثيم لا يزرع منتجات أو حسابات أو بوابات في موقعك.

اختُبر محلياً على المصدر الرسمي ذي الوسم v1.5.9، على PHP 8.3.35 و8.4.13. تفاصيل النتائج في `docs/VALIDATION.md`. هذا يثبت الفحوص المذكورة، ولا يثبت إعدادات خادمك أو الاتصال الحي ببواباتك وPterodactyl.

## التراجع الآمن

أداة التركيب تطبع مسار النسخة الاحتياطية وأمر التراجع الكامل. استخدم **المسار المطبوع نفسه**:

```bash
php install.php --root=/var/www/paymenter --rollback=/var/www/paymenter/storage/app/x3-theme-backups/اسم-النسخة
php install.php --root=/var/www/paymenter --rollback=/var/www/paymenter/storage/app/x3-theme-backups/اسم-النسخة --apply
```

الأمر الأول يفحص فقط؛ الثاني يعيد المجلدين السابقين ويحفظ النسخة المستبدلة داخل النسخة الاحتياطية. لا تحذف النسخ الاحتياطية حتى تنتهي من التحقق. التراجع عن الملفات لا يبدل إعدادات قاعدة البيانات؛ إذا كان هذا أول تركيب ولم يكن عندك ثيم X3 سابقاً، اختر `default` من الإدارة قبل التراجع.

للطوارئ إذا تعذر فتح الواجهة والإدارة، يمكنك اختيار الثيم الافتراضي من الطرفية دون تعديل ملفات core:

```bash
cd /var/www/paymenter
php artisan tinker --execute='App\Models\Setting::updateOrCreate(["key"=>"theme"],["value"=>"default","type"=>"string"]); App\Providers\SettingsProvider::flushCache();'
php artisan view:clear
```

إذا بقيت نسخة قديمة مع صحة الملفات، حدّث صفحة المتصفح تحديثاً كاملاً. الخوادم التي تعطل فحص تغيّر ملفات OPcache قد تحتاج إعادة تحميل PHP-FPM بواسطة مدير الخادم.
